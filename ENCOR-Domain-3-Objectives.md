# [Domain-3](#domain-3-infrastructure) **Infrastructure**

> 🤖 [AI Tutor](https://edureify.com/certification/exam/ccnp-encor) · 🎓 [Training](https://edureify.com/certification/networking/ccnp-encor/training) · 📝 [Practice Test](https://edureify.com/certification/networking/ccnp-encor/practice-test) · 🎯 [Mock Exam](https://edureify.com/certification/networking/ccnp-encor/mock-exam) · 📊 [Readiness Test](https://edureify.com/certification/networking/ccnp-encor/readiness-test) · 📄 [Cheat Sheet](https://edureify.com/certification/networking/ccnp-encor/cheat-sheet) · 📖 [Study Guide](https://edureify.com/certification/networking/ccnp-encor/study-guide)

- **30% weighting — the single heaviest domain by a wide margin.** Core Layer 2/Layer 3 technologies at enterprise scale; a widely used study plan spends two full months here before moving to any other domain

## Layer 2 technologies

- **VLANs and trunking**: extending CCNA's VLAN configuration into more complex, multi-switch enterprise topologies
- **Spanning Tree Protocol (STP/RSTP)**: rapid convergence and loop prevention at enterprise scale, building directly on CCNA's STP foundation with deeper failure-scenario analysis
- **EtherChannel**: link aggregation configuration and troubleshooting, extended from CCNA's introductory coverage
- **Layer 2 security**: port security, DHCP snooping, and dynamic ARP inspection — protecting the switched infrastructure from common Layer 2 attacks

## Layer 3 routing protocols

- **OSPFv2/v3, multi-area**: the exam's signature routing topic — extending CCNA's single-area OSPF into full multi-area design, including area types, route summarization, and inter-area route behavior
- **EIGRP**: Cisco's proprietary advanced distance-vector protocol — configuration, metric calculation, and convergence behavior
- **BGP fundamentals**: introductory Border Gateway Protocol configuration and path selection — the protocol that runs the internet's core routing, introduced here for enterprise edge/multi-homing scenarios
- **IPv6 routing**: applying the same routing protocol concepts in a dual-stack IPv4/IPv6 environment, reflecting ENCOR's explicit dual-stack architecture validation

## Multicast and QoS

- **IP multicast fundamentals**: how multicast traffic is distributed efficiently to multiple recipients, distinct from unicast routing covered elsewhere in this domain
- **Quality of Service (QoS)**: DSCP marking and queuing mechanisms to prioritize latency-sensitive traffic (e.g., voice/video) over best-effort traffic — note that v1.2 trimmed some legacy QoS configuration detail in favor of more current queuing concepts

## Wired and wireless infrastructure implementation

- **Implementing enterprise wired infrastructure**: applying the Layer 2/3 technologies above in realistic enterprise topologies
- **Implementing wireless infrastructure fundamentals**: 802.11 standards and basic wireless deployment, connecting to Domain 1's wireless architecture design content
