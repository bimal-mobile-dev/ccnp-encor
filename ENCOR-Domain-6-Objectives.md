- **15% weighting.** Renamed from simply "Automation" in v1.2, with increased emphasis reflecting how central network programmability has become to modern enterprise engineering — not an optional add-on skill anymore

## Programmability fundamentals

- **Python scripting for network automation**: applying scripting skill specifically to network device interaction — a more networking-focused application than the general-purpose scripting covered in Linux+'s Automation domain
- **REST API calls**: interacting with network devices and controllers (including Catalyst Center) programmatically via REST APIs, building on the HTTP verb and JSON concepts introduced at the CCNA level

## Configuration management and orchestration

- **NETCONF/YANG**: model-driven network configuration and management protocols — a more structured, standardized approach to device configuration than traditional CLI scripting
- **General orchestration concepts**: v1.2 deliberately removed specific vendor tool names (Chef, Puppet, Ansible, SaltStack) from the blueprint wording in favor of testing the underlying orchestration concepts — understand *what* orchestration accomplishes (consistent, automated, large-scale configuration management) rather than memorizing any single tool's syntax

## Ansible playbooks and infrastructure automation

- **Ansible playbook concepts**: despite the blueprint wording shift away from naming specific tools, Ansible remains the most commonly used real-world example for demonstrating playbook-based network automation in practice, and hands-on familiarity with it remains valuable prep even though the exam tests the underlying concept generally

## Artificial intelligence in network operations

- **AI-driven network operations**: the domain's new AI emphasis — understanding how AI/ML techniques (predictive analytics, anomaly detection) are increasingly integrated into enterprise network monitoring and management, particularly through platforms like Cisco Catalyst Center, connecting directly to Domain 4's assurance content
- This mirrors the same AI-in-networking theme introduced conceptually at the CCNA level, now expected at a deeper, more applied understanding for a professional-level engineer
