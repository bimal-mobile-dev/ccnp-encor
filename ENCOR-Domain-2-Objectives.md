- **10% weighting** — the smallest domain tied with Network Assurance, but foundational to understanding how modern enterprise networks actually virtualize infrastructure

## Device and network virtualization

- **Virtual switching**: how virtual switches operate within a virtualized server environment, connecting virtual machines to the physical network
- **Network Functions Virtualization (NFV)**: running traditionally hardware-based network functions (firewalls, routers) as software instances instead — a growing enterprise deployment pattern

## VRF and virtual network segmentation

- **VRF-lite (Virtual Routing and Forwarding)**: creating multiple independent routing tables on a single physical device, allowing logically separate networks to share physical infrastructure without routing table conflicts — a heavily tested configuration and conceptual topic

## Data center virtualization concepts

- **Virtual machine and container awareness at the network layer**: understanding how virtualized and containerized workloads connect to and are addressed on the enterprise network, distinct from a server administrator's perspective on the same technologies
