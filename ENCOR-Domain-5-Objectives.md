- **20% weighting** — the exam's second-heaviest domain, and one of the two most changed areas in v1.2 alongside Automation and AI

## Wireless security (expanded in v1.2)

- **802.1X**: port-based network access control, extending the authentication framework concept beyond wired ports into wireless authentication
- **WebAuth and PSK**: web-based authentication portals and pre-shared key authentication as alternative wireless security models suited to different deployment scenarios (guest access vs. trusted device access)
- **EAPOL 4-way handshake**: the specific process by which a wireless client and access point establish an encrypted session key — a v1.2 addition reflecting deeper wireless security mechanics than prior versions tested

## Access control and segmentation

- **TrustSec**: Cisco's software-defined segmentation technology, using security group tags to enforce policy independent of network topology — a more scalable alternative to traditional VLAN/ACL-based segmentation
- **Access Control Lists (ACLs)**: enterprise-scale ACL design and troubleshooting, extending CCNA's foundational ACL configuration

## VPN technologies

- **DMVPN and FlexVPN**: Cisco's dynamic, scalable site-to-site VPN technologies for connecting many enterprise sites without manually configuring a full mesh of static tunnels — a step beyond CCNA's introductory VPN concepts into actual enterprise-scale VPN architecture

## Security fundamentals at enterprise scale

- **Threat defense integration**: understanding how enterprise network infrastructure integrates with dedicated security appliances and services, applying the broader security concepts from Security+ and CCNA's Security Fundamentals domain at enterprise scale and complexity
